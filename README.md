# Лабораторная работа по дискретной матиматике

## Реализация алгоритмов лежит в файле `/internal/service/graph.go`

## для работы с програмой необходимо установить Docker

## Для запуска программы неообходимо:
1. создать файл .env и перенести туда креды из .env.template (или вставить свои)
2. выполнить в терминале

`docker-compose up --build`

## после запуска тнеобходимо открыть html файл из папки /service через любой браузер

В рамках лабороторной работы был реализован http сервис на ЯП Go с использованием фреймворков gin - для http взаимодействия и gorm - для взаимодействия сервиса с бд.
Данные взаиможействи с сервисом сохраняются в СУБД Postgreds
